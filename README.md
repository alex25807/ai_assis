# ИИ-ассистент «Народные окна»

Две версии:

- **Продакшен в Savvy** — живой Telegram-бот [@narrodnyeoknaa_bot](https://t.me/narrodnyeoknaa_bot). Этот репозиторий его **не отключает и не перехватывает**.
- **Улучшенная копия в коде** — Python-бот в каталоге `bot/`. Запускается только на **отдельном** токене BotFather, пишет в **свой** календарь (SQLite по умолчанию).

Скриншоты исходного Savvy-диалога лежат в корне репозитория.

## Что улучшено относительно Savvy-версии

- Приветствие без лишних кавычек, меню кнопками: замер, цены, сроки, менеджер.
- Заявка собирается **по одному полю**: имя → телефон → адрес → дата → час.
- Телефон вроде `0000000` не принимается; адрес обязателен.
- Слот попадает в календарь только после кнопки «Подтвердить».
- Повторный `/start` не создаёт вторую запись: предлагает продолжить или отменить.
- Занятый час предлагает соседние **целые** часы (14:00, 15:00), не 15:15.
- График как на [oknagealan.ru](https://oknagealan.ru/): пн–сб **10:00–18:00**, воскресенье выходной. Часовой пояс `Asia/Chita`.
- Ответы про цену и сроки опираются на базу знаний в git, без выдуманных рублей (вилка цен — `TBD`, пока владелец не подтвердит).

## Запуск копии в коде

Нужны Python 3.12+ и **тестовый** токен. Не вставляйте токен `@narrodnyeoknaa_bot`: Telegram отдаёт апдейты только одному получателю, Savvy перестанет отвечать клиентам.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# заполните TELEGRAM_BOT_TOKEN тестового бота
python -m bot
```

Без токена можно прогнать диалог в терминале:

```bash
python -m bot.simulate
```

Переменные окружения — в [`.env.example`](.env.example). `CALENDAR_BACKEND=local` (по умолчанию) хранит слоты в SQLite и **не** пишет в Google-календарь Savvy. Режим `google` включайте только с отдельным `GOOGLE_CALENDAR_ID`.

Опционально: `LLM_API_KEY` для Qwen/OpenAI-совместимого API. Без ключа бот отвечает встроенным FAQ из базы знаний.
